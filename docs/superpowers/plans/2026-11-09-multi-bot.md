# 複数Bot（最大10個）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One app holds many bots; each starts, stops and restarts on its own, and the home screen shows them all at a glance.

**Architecture:** Pure, JVM-tested pieces first (names, registry, per-bot store, one-time migration, shared-folder rules, a fleet of runners), then the Android glue (`BotController` keyed by bot id, one `BotService` hosting a `BotFleet`), then the UI (home → detail with 4 tabs → app settings), which replaces `SpikeScreen`. Every commit builds.

**Tech Stack:** Kotlin, Jetpack Compose (Material3), kotlin.test on JVM, Gradle. No new dependencies (no Navigation library).

**Spec:** `docs/superpowers/specs/2026-11-09-multi-bot-design.md` (Japanese). Read it before any task.

## Global Constraints

- minSdk 26, arm64 only. No new libraries.
- UI copy is Japanese, exactly as the spec quotes it where it quotes it (「＋ Botを追加」「✏ 変更あり」「📁 フォルダが見つかりません」「フォルダを作り直す」「🔒 アプリの中だけ（フォルダには出ません）」「一覧から外すだけ（フォルダは残す）」「フォルダも削除する」「秘密の値も消えます」「同じ名前のフォルダがあります」「ほかのBotの取り込み中です」「新しいフォルダが見つかりました」「最初のBotを追加しましょう」「『<名前>』がエラーで停止しました」「N個のBotが稼働中」「10個を超えると、スマホによっては動きが重くなることがあります」).
- Bot names: trimmed, 1–40 chars, none of `/ \ : * ? " < > |` or control chars, not starting with `.`, unique ignoring case.
- Shared root: `Documents/PythonRunner/`; each bot's shared folder is `PythonRunner/<Bot名>`. The app puts nothing else there.
- Private layout per bot: `filesDir/bots/<id>/code/`, `libs/`, `shared.manifest`, `import-staging/`, `import-backup/`. Registry: `filesDir/bots/registry.txt`.
- Secrets never go to shared storage, never to pip. Bot code always runs from `code/`, never from shared storage.
- The migrated bot has id `mybot` and name `MyBot`.
- Gradle check on this PC (PowerShell): `$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-17.0.20.101-hotspot"; .\gradlew.bat testDebugUnitTest assembleDebug lintDebug --console=plain` — "Gradle check" below means this, expecting `BUILD SUCCESSFUL`.
- Single test class: `.\gradlew.bat testDebugUnitTest --tests "com.pythonrunner.app.bot.BotNamesTest" --console=plain`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never add the user's `android/` folder.

## Review Focus

1. Renaming a bot by case only (`MyBot` → `mybot`): shared storage is case-insensitive; expect the folder to end up with the new case (rename through a temporary name). Test in Task 5.
2. Fresh install (no old `spike` data): expect an empty list and no `MyBot`. Test in Task 4.
3. Old secrets and main file exist but `bots/spike` was deleted: expect `MyBot` with its secrets kept. Test in Task 4.
4. Folders in `PythonRunner/` that differ from a bot name only by case, hidden folders (`.thumbnails`), and plain files: expect only real, unlisted, non-hidden folders offered. Test in Task 5.
5. Adopting a found folder that holds `.env`, `__pycache__/`, `token.json`: expect them neither copied into the vault nor removed from the folder. Test in Task 5.
