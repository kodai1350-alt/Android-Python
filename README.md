# Python Runner（お試し版）

Androidスマホで Python のスクリプト（Discord Bot など）を、**画面を消したまま動かし続ける**ためのアプリです。
公式の Python 3.14 をアプリに同梱しているので、別に Python を入れる必要はありません。

今はお試し版です。Bot を1つだけ動かせます。複数のBotや見やすいホーム画面は、次の版で作ります。

- 対応端末: Android 8.0 以上、64ビット（arm64）
- Google Play では配布していません。このページの Releases からダウンロードします。

## インストール手順

1. スマホのブラウザでこのリポジトリの **Releases** を開き、最新の `PythonRunner-vX.Y.Z.apk` をダウンロードします。
2. ダウンロードした apk を開きます。
   「提供元不明のアプリ」の確認が出たら、そのブラウザ（または「ファイル」アプリ）からのインストールを**許可**します。
   Android 8 では、アプリごとに許可する方式です（設定 → アプリと通知 → 詳細設定 → 特別なアプリアクセス → 不明なアプリのインストール）。
3. 「インストール」を押します。

アップデートするときも、同じ手順で新しい apk を入れれば上書きされます（Bot のファイルや設定は残ります）。

## お試し版の使い方

画面は上から順番に操作します。

1. **Pythonの準備**: 「Pythonを準備」を押します。Python のバージョンと OpenSSL のバージョンが表示され、「✓ 準備完了」になれば成功です。
2. **Botのファイル**: 「.pyファイルを追加」で、Bot の .py ファイルを取り込みます。
   下に PC のエクスプローラーと同じ形の画面があります。
   - 左のナビゲーション（☰ で出し入れ）：⭐ Bot のフォルダ／📱 このスマホ（共有）の内部ストレージ・Documents・Download／🔒 アプリ専用の Python 本体・ライブラリ
   - 右側：アドレスバー（名前を押すと戻れる）、⬆ 上へ、実際の保存場所、名前・更新日時・サイズ
   - 📁 フォルダを押すと中に入り、ファイルを押すとメニューが出ます。緑の「▶ 最初に実行」が起動するファイルで、Bot のフォルダの .py ならメニューから切り替えられます。

   「ストレージへのアクセスを許可する」を押すと、Bot のファイルの**コピー**がスマホの `Documents/PythonRunner/MyBot` に置かれ、
   「ファイル」アプリや USB でつないだ PC から見たり編集したりできます。
   - 実行するのは、アプリ専用の場所（他のアプリから書き換えられない）にある本体です。
   - 共有のコピーで追加・変更・削除があると、「起動」を押したときに一覧が出ます。自分で編集したものなら「取り込んで起動」、心当たりがなければ「取り込まずに起動」か「やめる」を選びます。
   - Bot が作ったデータは、停止したときと「🔄 更新」を押したときに共有のコピーへ反映されます。共有側であなたが編集・削除したファイルを上書きしたり復活させたりはしません。
   - 共有のコピーは、ストレージの許可を持つ他のアプリからも読めます。`.env`、鍵（.pem/.key など）、データベース（.db/.sqlite）、
     名前に token・secret・credential・password を含むファイルはコピーしません。
     トークンは .py や config.json に書かず、「4. 秘密の値」（アプリ専用）に入れてください。
3. **ライブラリ（pip install）**: ネットで見つけた `pip install discord.py aiohttp` のようなコマンドを、そのまま貼り付けて「インストール」を押します。
   `pip3 install -U …`、`python -m pip install …`、複数行もそのまま使えます。パッケージ名だけを並べても大丈夫です。
   Bot が `ModuleNotFoundError: No module named 'xxx'` で止まったら、`xxx` を入れてインストールしてください。
4. **秘密の値（使わなくてもOK）**: トークンを Bot のコードに直接書かずに済ませるための保管場所です。
   「＋追加」で `TOKEN` のような名前と値を入れて「保存」すると、Bot の中で `os.environ["TOKEN"]` で読めます。
   コードにトークンを直接書いているなら、ここは空のままで大丈夫です。
   「👁 表示」で値を確認、「🗑 削除」で行を消せます（消したあとも「保存」を押してください）。
5. **AIモデル（LLM）**: 質問Bot（下の askbot）が使う AI モデル（約1.25GB）をダウンロードします。Wi-Fi でどうぞ。
   途中で止まっても、もう一度押すと続きから再開します。ダウンロードしてあれば、Bot を起動したときに一緒に動きます。
   「使うCPUの数」は、遅いと感じたら変えてみてください（次の起動から）。
6. **実行**: 「起動」を押します。止めるときは「停止」です。
7. **ログ**: Bot の `print` やエラーが表示されます。「コピー」で全文をコピーできます。

## 質問Bot（askbot）の使い方

Discord で @メンションすると、スマホの中の AI（LFM3-VL-2B）が答える Bot です。写真への質問、知らない分野（Wikipedia で調べて答える）、前の会話探しができます。すべて無料です。
アプリで同時に動かせる Bot は1つなので、今の Bot とは入れ替えになります。

1. [Discord Developer Portal](https://discord.com/developers/applications) で Bot を作ります。
   - 「Bot」のページで **Message Content Intent をオン**にします（メッセージの中身を読むために必要です）。
   - 「OAuth2 → URL Generator」で、スコープ `bot` と `applications.commands`、
     権限「チャンネルを見る」「メッセージを送信」「メッセージ履歴を読む」を選び、出てきた URL でサーバーに招待します。
2. アプリの「3. ライブラリ」で `pip install discord.py` を実行します。
3. [Releases](https://github.com/kodai1350-alt/Android-Python/releases) から `askbot.py` をダウンロードし、
   「2. Botのファイル」の「📄 .pyファイルを追加」で取り込みます（「▶ 最初に実行」になります）。
4. 「4. 秘密の値」に、名前 `TOKEN`・値に Bot のトークンを入れて「保存」します。
5. 「5. AIモデル」でダウンロードします。
6. 「6. 実行」で「起動」します。ログに「[AIモデル] 起動します」と「logged in as …」が出れば準備完了です。
7. 前の会話を探したいチャンネルで `/記録する` を実行します（過去365日分を読み込みます）。やめるときは `/記録やめる`（保存した分も消えます）。

使い方の例:
- 写真に返信して「@Bot これ何？」
- 「@Bot 量子コンピュータって何？」 → Wikipedia を読んで答え、参考ページのリンクを付けます。
- 「@Bot 先週ラーメン屋の話したけど、どこだっけ？」「@Bot 10月20日に話してたゲームの名前なんだっけ？」 → 元のメッセージへのリンク付きで答えます。

知っておいてほしいこと:
- スマホの中で考えるので、写真や資料を読むのに数分かかることがあります。読んでいる間は「📖 Wikipediaを読んでいます… 60%」のように進み具合が出ます。
- 一度に答えるのは1人ずつです。ほかの人は「順番待ち 1番目です」と表示されます。1人が同時に聞けるのは1つまでです。
- 前の会話は、`/記録する` をしたチャンネルのうち、質問した人が読めるチャンネルからだけ探します。
- 写真は1つの質問につき2枚まで、1枚8MBまでです。

## 画面オフで動かし続けるための設定

Android は電池を節約するために、裏で動いているアプリを止めることがあります。次の2つを必ず設定してください。

1. アプリの「8. 端末の設定」にある **「電池の最適化を除外する」** を押して許可します。
2. ZenFone などの ASUS 端末では、**モバイルマネージャー → 自動起動マネージャー**（または「省電力」の設定）で、Python Runner を許可します。

Bot が動いている間は、通知欄に「Python Runner：Botが稼働中」と表示されます。これが出ている間は動いています。
Bot がエラーで止まったときは、別の通知でお知らせします。

## 開発者向け

### ビルド

```bash
./gradlew testDebugUnitTest assembleDebug
```

JDK 17、Android SDK（platform 37.0）、NDK 29.0.14206865 が必要です。ビルドのときに Python 本体を python.org から自動でダウンロードします。

### リリースの作り方

1. （最初の1回だけ）署名鍵を作ります。

   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\make-keystore.ps1
   ```

   表示された4つの値を、GitHub の **Settings → Secrets and variables → Actions** に登録します（`KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD`）。

2. タグを push すると、GitHub Actions が署名済みの apk を作って Releases に置きます。

   ```bash
   git tag v0.1.0
   git push origin v0.1.0
   ```

> **重要:** `pythonrunner.jks` とパスワードは必ずバックアップしてください。
> なくすと、同じアプリとしてアップデートできなくなります（一度アンインストールが必要になり、Bot のデータも消えます）。
