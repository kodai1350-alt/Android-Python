# Python Runner

Androidスマホで Python のスクリプト（Discord Bot など）を、**画面を消したまま動かし続ける**ためのアプリです。
公式の Python 3.14 をアプリに同梱しているので、別に Python を入れる必要はありません。
Bot はいくつでも追加でき（目安は10個まで）、それぞれ別々に起動・停止できます。

- 対応端末: Android 8.0 以上、64ビット（arm64）
- Google Play では配布していません。このページの Releases からダウンロードします。

## インストール手順

1. スマホのブラウザでこのリポジトリの **Releases** を開き、最新の `PythonRunner-vX.Y.Z.apk` をダウンロードします。
2. ダウンロードした apk を開きます。
   「提供元不明のアプリ」の確認が出たら、そのブラウザ（または「ファイル」アプリ）からのインストールを**許可**します。
   Android 8 では、アプリごとに許可する方式です（設定 → アプリと通知 → 詳細設定 → 特別なアプリアクセス → 不明なアプリのインストール）。
3. 「インストール」を押します。

アップデートするときも、同じ手順で新しい apk を入れれば上書きされます（Bot のファイルや設定は残ります）。

## 使い方

### ホーム画面

アプリを開くと、すべての Bot が一覧で並びます。

- いちばん上の数字で、全体の様子が分かります：**稼働中**（緑）／**エラー**（赤）／**停止中**。
- Bot ごとのカードの見方
  - 点の色：🟢 稼働中　🟡 起動中　🔴 エラーで停止（カードの枠も赤くなります）　⚪ 停止中
  - 「起動」「停止」ボタン、最新のログ2行、ファイルの場所（📁 ドキュメント › PythonRunner › Bot名）
  - **✏ 変更あり**：ファイルアプリや PC でその Bot のファイルを変えると出ます。押すと何が変わったかの一覧が出て、「反映する」で Bot に取り込みます。
  - **📁 フォルダが見つかりません**：共有フォルダごと消したときに出ます。Bot のファイルは消えていません。「フォルダを作り直す」でもう一度置けます。
- カードを押すと、その Bot の詳しい画面が開きます。
- 右上の「⚙ 設定」は、アプリ全体の設定です（Pythonの準備、ファイルの共有、端末の設定）。

### Bot を追加する

1. ホーム画面の **「＋ Botを追加」** を押し、「ファイルを選ぶ（.py・ZIP など）」か「フォルダを選ぶ」を選びます。
   Googleドライブのフォルダは、ドライブで ZIP としてダウンロードしてから「ファイルを選ぶ」で取り込めます。
2. 名前を確かめて「追加する」を押します。名前はフォルダ名・ZIP名から自動で入ります。
3. その Bot の画面が開きます。`requirements.txt` があれば「ライブラリ」タブに中身が入っているので、「インストール」を押します。
   トークンは Bot のフォルダの `.env`（`DISCORD_TOKEN=…` のように書く）に入れます。「設定」タブの「.env」でも作れます。
4. 「起動」を押します。

PC などで `ドキュメント/PythonRunner/` に直接フォルダを作ったときは、ホーム画面の下に
「新しいフォルダが見つかりました」と出ます。「追加する」を押すと、そのフォルダがそのまま Bot になります。

### Bot の画面（4つのタブ）

- **ログ**：Bot の `print` やエラー。「コピー」で全文をコピー、「🗑 ログを消す」で空にできます。
- **ファイル**：PC のエクスプローラー（Windows 11）と同じように使えます。
  - **選ぶ・開く**：タップで選び（青くなる）、選んだものをもう一度タップで開きます。左の ☐ で何個でも選べます。何もないところをタップすると選択が外れます。
  - **長押し ＝ 右クリック**：開く・切り取り・コピー・名前の変更・削除・プロパティ。`.py` なら「▶ これを最初に実行」も出ます。
  - **上のツールバー**：新規（フォルダー・テキスト ドキュメント・Python ファイル）・切り取り・コピー・貼り付け・名前の変更・削除・元に戻す。
    コピーしたものは、別の Bot にも貼り付けられます。列の見出し（名前・更新日時・サイズ）をタップすると並べ替えます。
  - **ごみ箱**：削除したものは左の「ごみ箱」に入り、「元に戻す」で元の場所に戻せます。「ごみ箱を空にする」を押すまで残ります。
    取り込みや「反映する」で置き換わったり消えたりしたファイルも、ごみ箱に入ります。
  - **元に戻す**：直前の操作から順に、Bot ごとに 20 回まで取り消せます（アプリを完全に閉じるまで）。ファイルがその後に変わっていたら止まります。
  - **同じ名前があるとき**：Windows と同じく「ファイルを置き換える／ファイルをスキップする／ファイルごとに決める」から選びます。
  - **メモ帳**：文字のファイルを開くと、アプリの中で見て直せます（1MB まで）。文字コード（UTF-8・Shift_JIS）と改行はそのまま保たれます。
    保存しないで閉じると「保存しますか？」と聞きます。Bot が動いている間に保存したときは「今すぐ再起動」で反映できます。
  - **取り込む**：「📁 フォルダを取り込む」「📄 ファイルを取り込む」は、いま開いている場所に入ります（同じ名前のフォルダは中身が合わさります）。
    「🔄 Botをまるごと入れ替える」でフォルダか ZIP を選ぶと、その中身が Bot になります。新しいフォルダにないもの（スマホで登録したデータなど）は、最初は「残す」です。
  - PC などで変えて、まだ「反映」していないファイルを操作しようとすると、先に反映するよう聞きます（どちらの変更も消えないように）。
  - `node_modules`・`.venv` は、アプリが入れた部品です（薄い色で出ます）。コピーされず、それだけを消したり動かしたりはできません。`__pycache__`・`.git`・`venv` は取り込みません。
  - 🔒 の付いたファイル（鍵 `.key`・データベース `.db` など）は、アプリの中だけにあり、共有フォルダには出ません。`.env` は共有フォルダにも置かれます。
- **ライブラリ**：一番上の「入っているもの」に、入っているライブラリと版、部品の状態（✓ 入っています・✗ まだ・! 入れ直し）が出ます。
  `requirements.txt` や `package.json` がある Bot は、「部品を入れる」で Python のライブラリと Node.js の部品をまとめて入れます（Bot は自動で止めて、終わったら起動し直します）。
  そのほかは、ネットで見つけた `pip install discord.py aiohttp` のようなコマンドを、そのまま貼り付けて「インストール」を押します。
  ライブラリは Bot ごとに別々に入ります。Bot が `ModuleNotFoundError: No module named 'xxx'` で止まったら、`xxx` を入れてください。
  初めて使う前に「⚙ 設定」の「Pythonの準備」を1回してください。
- **設定**：最初に実行するファイル、.env、Bot の名前の変更、Bot の削除。
  - **.env**：ふだんは名前だけが見えます。「表示して編集」で中身を直して「保存」すると、Bot の中で `os.environ["名前"]` で読めます。
    PATH・LD_〜・PYTHON〜（PYTHONIOENCODING などを除く）・NODE_〜・〜_PROXY のように、プログラムの読み込み方を変える名前は、安全のため使いません（ログに出ます）。
  - **名前の変更**：共有フォルダの名前も一緒に変わります。
  - **削除**：アプリの中のファイル・ライブラリ・設定と、共有フォルダの両方を消します。元に戻せません。

### ファイルの置き場所

覚えておくのは、**「ドキュメント → PythonRunner → Bot名のフォルダ」がその Bot** ということだけです。

```
ドキュメント/PythonRunner/
├─ 紬/          ← フォルダ名 ＝ アプリでの Bot 名
│  ├─ persona.txt
│  └─ src/bot.py
└─ 音楽Bot/
   └─ main.py
```

（「⚙ 設定」で「ストレージへのアクセスを許可する」を押すと、このフォルダが作られます。）

実際に動いているのは、アプリの中にある同じ内容のファイルです。他のアプリから書き換えられないようにするためです。
共有フォルダのファイルを直すと、アプリが「✏ 変更あり」と知らせ、「反映する」を押したときだけアプリの中も変わります。
心当たりがない変更は、他のアプリが書き換えた可能性があるので「反映しない」を選んでください。

- 共有フォルダは、ストレージの許可を持つ他のアプリからも読めます。**トークンを書いた `.env` も共有フォルダに置かれます**。
  漏れたと思ったら、Discord の開発者ページでトークンを作り直してください。
  鍵（.pem/.key など）、データベース（.db/.sqlite）、`.env.local` などの `.env` の変種、名前に token・secret・credential・password を含むファイルはコピーしません。
- Bot が作ったデータは、停止したときとアプリを開いたときに共有フォルダへ反映されます。共有側であなたが編集・削除したファイルを上書きしたり復活させたりはしません。

### 前の版（お試し版）からのアップデート

前の版で動かしていた Bot は、アップデートすると **「MyBot」** という名前で一覧の1個目に入ります。
ファイル・ライブラリはそのまま残ります。前の版の「秘密の値」は、アップデート後の最初の起動で、その Bot の `.env` に移ります。名前は「設定」タブで変えられます。

### 気をつけること

このアプリの Bot は、どれも同じアプリの権限で動きます。そのため、ある Bot のプログラムは、ほかの Bot のファイルや `.env` を読めてしまいます。
**中身を信用できる Bot だけ**を追加してください。

## 画面オフで動かし続けるための設定

Android は電池を節約するために、裏で動いているアプリを止めることがあります。次の2つを必ず設定してください。

1. 「⚙ 設定」の「端末の設定」にある **「電池の最適化を除外する」** を押して許可します。
2. ZenFone などの ASUS 端末では、**モバイルマネージャー → 自動起動マネージャー**（または「省電力」の設定）で、Python Runner を許可します。

Bot が動いている間は、通知欄に「Python Runner：2個のBotが稼働中」のように表示されます。これが出ている間は動いています。
Bot がエラーで止まったときは、「『Bot名』がエラーで停止しました」と Bot ごとに別の通知でお知らせします。

## 開発者向け

### ビルド

```bash
./gradlew testDebugUnitTest assembleDebug
```

JDK 17、Android SDK（platform 37.0）、NDK 29.0.14206865 が必要です。ビルドのときに Python 本体を python.org から自動でダウンロードします。

### リリースの作り方

1. （最初の1回だけ）署名鍵を作ります。

   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\make-keystore.ps1
   ```

   表示された4つの値を、GitHub の **Settings → Secrets and variables → Actions** に登録します（`KEYSTORE_BASE64` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD`）。

2. タグを push すると、GitHub Actions が署名済みの apk を作って Releases に置きます。

   ```bash
   git tag v0.1.0
   git push origin v0.1.0
   ```

> **重要:** `pythonrunner.jks` とパスワードは必ずバックアップしてください。
> なくすと、同じアプリとしてアップデートできなくなります（一度アンインストールが必要になり、Bot のデータも消えます）。
